Episode 34

Your n8n node runs once for every item you send it — not once, total.

n8n's real execution model: a node runs once per item in the array it receives, not once per workflow. An HTTP Request node on 40 rows makes 40 real calls — not one call with 40 rows in it. The fix is the Loop Over Items node (Split in Batches), which groups items before they hit the expensive step.
