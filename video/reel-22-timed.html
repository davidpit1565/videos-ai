Episode 22

n8n can lie to you, and still show green

In n8n, when an AI Agent calls a tool and that tool fails, the Agent itself can still finish green — a real, open, unresolved issue on n8n's own GitHub. We built one: one agent, one tool, one deliberately broken key. The tool failed. The dashboard called it a success. If you build automations like this for a client, you won't be the one who notices — they will. The fix is one workflow: n8n's own error trigger, checking the Agent's real output instead of its color.
