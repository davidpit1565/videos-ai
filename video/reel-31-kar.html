Episode 31 — Experiment 2

Your AI chatbot can run completely offline — it just doesn't know it can.

This model's network was cut at the system level — asked directly, it still guessed "I'm cloud-based, I need the internet." It's wrong: it's running entirely on this machine, via Ollama, a free open-source tool that runs real models like Llama completely offline. One command downloads the model once; after that the network is optional.
