Episode 29

Your n8n workflow can fail completely — and still say 'Success.'

A real, sourced n8n behavior: a node's "On Error" setting can be set to "Continue," built to survive a small hiccup — but when the node genuinely fails, n8n doesn't flag the workflow at all. The Executions list still reads green. The only place the failure actually shows is buried inside that one node's own output. A real community report confirms it: a workflow stayed silently broken for weeks while the log insisted everything was fine. One extra check — a branch watching for the error field — catches it immediately.
