Episode 35

Your n8n automation can say "done" — and still do it twice.

n8n's Webhook node, on its default "When Last Node Finishes" setting, holds its reply until the whole automation completes. If that takes more than a few seconds, whatever sent the original event has no way to know it's still being handled — so it sends the exact same event again, and n8n runs the entire automation a second time. The fix is the Respond to Webhook node: reply "got it" the instant the event arrives, then do the real work after.
