# חיבור המערכת לאינסטגרם — מדריך מלא

## קודם כול, האמת

**אין קונקטור לאינסטגרם.** בדקתי גם את החשבון שלך וגם את הרישום הציבורי של הקונקטורים —
לא קיים כזה. אף אחד לא יכול "לחבר" אותי לאינסטגרם שלך בלחיצה.

מה שכן קיים זה **Instagram Graph API** — הדרך הרשמית של מטא לפרסום אוטומטי. היא עובדת,
היא חוקית, והיא בדיוק מה שכלים כמו Later ו-Buffer משתמשים בהם מתחת למכסה.

ההבדל: הטוקן שייך לך ורץ מהמחשב שלך, לא מהסשן הזה. אני בניתי את הסקריפט —
אתה מריץ אותו. הגדרה חד־פעמית של בערך 20 דקות, ואחר כך זו פקודה אחת לכל סרטון.

---

## שלב 1 · חשבון מקצועי (3 דקות)

1. אינסטגרם → Settings → **Account type** → החלף ל־**Professional / Creator**
2. חבר אותו לדף פייסבוק. אין לך? צור אחד ריק — הוא נדרש טכנית ואף אחד לא צריך לראות אותו.

> בלי חשבון מקצועי מחובר לדף, ה־API פשוט לא יעבוד. זה לא עוקף.

## שלב 2 · אפליקציית מטא (8 דקות)

1. developers.facebook.com → **My Apps** → **Create App**
2. סוג: **Business**
3. הוסף את המוצר **Instagram Graph API**
4. תחת Permissions, בקש: `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`

## שלב 3 · טוקן ארוך־טווח (6 דקות)

1. **Graph API Explorer** → בחר את האפליקציה שלך → Generate Access Token, עם ההרשאות מלמעלה
2. הטוקן שמתקבל חי שעה. להפוך אותו לארוך (60 יום):
   ```
   GET https://graph.facebook.com/v21.0/oauth/access_token
     ?grant_type=fb_exchange_token
     &client_id=<APP_ID>
     &client_secret=<APP_SECRET>
     &fb_exchange_token=<SHORT_TOKEN>
   ```
3. את מזהה המשתמש של אינסטגרם:
   ```
   GET https://graph.facebook.com/v21.0/me/accounts?access_token=<TOKEN>
   GET https://graph.facebook.com/v21.0/<PAGE_ID>?fields=instagram_business_account&access_token=<TOKEN>
   ```

**הטוקן פג כל 60 יום.** שים תזכורת ביומן ליום 55. זו הסיבה הכי נפוצה שמערכות כאלה
נשברות בשקט — הכל עובד חודשיים ואז מפסיק בלי הודעה.

## שלב 4 · אחסון הווידאו (5 דקות)

אינסטגרם **לא מקבלת קובץ מהמחשב**. היא מושכת אותו מכתובת ציבורית, אז ה־MP4 חייב
לשבת איפשהו נגיש.

| אפשרות | עלות | הערה |
|---|---|---|
| **Cloudflare R2** | חינם עד 10GB | ההמלצה שלי. S3־תואם, בלי עמלות יציאה |
| **GitHub Releases** | חינם | הכי מהיר להתחיל — העלה את ה־MP4 כ־asset ל־release |
| Backblaze B2 | כמעט חינם | עובד מצוין |
| ~~Google Drive / Dropbox~~ | — | **לא עובד.** קישורי שיתוף מחזירים דף HTML, לא וידאו |

הסקריפט בודק את זה בשבילך לפני שהוא מנסה לפרסם, ואומר לך אם הכתובת לא תקינה.

## שלב 5 · פרסום

```bash
export IG_USER_ID=17841400000000000
export IG_ACCESS_TOKEN=EAAG...

python3 publish/instagram_publish.py \
  --video https://your-bucket.r2.dev/reel-01.mp4 \
  --caption captions/reel-01.txt \
  --dry-run          # בדיקה יבשה — לא מפרסם כלום
```

מרוצה? הורד את `--dry-run`.

- אם דלף — developers.facebook.com → App → Settings → **Reset App Secret**, וכל הטוקנים מתים מיד.
