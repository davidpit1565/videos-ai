# Source of the ig-* skills (installed 12.11.2026, David's instruction)
From https://github.com/Jakeschincariol/instagram-agent-skill (commit d03c56b, 13 Sep 2026, MIT, Copyright (c) 2026 Jake Schincariol). Copied unchanged: ig-reel, ig-viral, ig-caption, ig-human, ig-audit, ig-profile. NOT installed: ig-plan (we have our own weekly loop), ig-carousel, ig-story, ig-comment, ig-dm, ig-reply, ig-repurpose (not needed for faceless reels now).
Static review before install (12.11.2026): the Python files only read stdin or a given file and write to stdout or a given --out path; no network, no subprocess, no environment or secrets access.
How these fit THIS repo (read before using): our rules win where they differ. (1) The safe zone in ig-reel (y 230-1440) differs from Meta's published numbers we use (x 65-1015, y 269-1248): use ours. (2) hooks.json and hookscore.py are the author's heuristics, not evidence; `channel/hook-research-20-10.md` found no proven hook formula, so hookscore is a checklist, never a gate. (3) The skills assume a creator on camera and a ~/.claude/instagram/voice.md voice profile: ours is the cloned voice and Miki style, faceless. (4) ig-viral's outlier multiple (views divided by that account's own recent median) is the one idea we adopt fully, including for our own reels.
