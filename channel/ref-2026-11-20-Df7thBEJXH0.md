## Verified live 20.11.2026 (github.com/Crosstalk-Solutions/project-nomad, projectnomad.us)
- Real: "an offline-first knowledge and education server": offline Wikipedia, medical references, ebooks via Kiwix; offline maps via Protomaps; an optional local AI; Apache licence text appears on the page; install is a script for Debian-based systems (Ubuntu 26.04 LTS recommended, 24.04 and Debian 12 supported); stars about 43k (the reel's on-screen counter 43,475 matches the page). Third parties covered it (TechHut, r/selfhosted, r/DataHoarder).
- The reel's "one catch" is true and is the honest part: download BEFORE the outage. Local AI "needs more capable hardware" (the caption says so; the voiceover does not).
- Not verified by us: that it works as shown in a real outage (we did not install it), exact disk sizes, Windows/WSL2 details.
