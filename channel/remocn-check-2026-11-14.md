- Repo Remocn/remocn, MIT, last commit 11.11.2026. README claims 932 components; real count by folder: 787 animation components + 101 icons + 6 templates + 46 UI = 940. The reel's "825" is loose, not a number the repo states.
- They are React components that need the Remotion runtime (frame clock). Using them as-is = switching our renderer (HyperFrames/GSAP) to Remotion. Simple text/transition effects can be re-implemented in GSAP by hand; shader/three.js and app-simulation ones cannot.
- Remotion licence (not MIT): free for individuals and companies of up to 3 people; company licence required beyond that (https://www.remotion.dev/docs/license/pricing). Prices from search snippets UNVERIFIED.
- They carry the clean spring-driven "AI motion graphics" look that Roni's 10.11 rule says to avoid.
- Verdict: PORT IDEAS ONLY, do not adopt. Revisit only for non-reel product-demo videos.
