If it failed right now, would you even know?

In n8n, when an AI Agent calls a tool and that tool fails, the Agent itself can still
finish green — a real, open, unresolved issue on n8n's own GitHub right now. We built
one: one agent, one tool, one deliberately broken key. The tool failed. The dashboard
called it a success.

n8n treats the tool's failure as part of the Agent's own reasoning, not as an
execution error — so the built-in Error Workflow never fires.

If you build automations like this for a client, you won't be the one who notices.
They will.

The fix isn't just n8n's error trigger — that alone doesn't catch this. It's making
every tool report its status honestly, checking that status right after the Agent,
and only then wiring up the alert. Full setup, exact clicks: actually-works.com/e/22

Follow for the setup that actually works.
