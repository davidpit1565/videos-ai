# YouTube description — chapter markers

Paste this block into the description. YouTube builds the chapters from it as long
as the first is 00:00 and there are at least three.

```
0:00 Hook
0:32 What this actually is
1:43 Shortcuts vs. automatic
3:04 What's happening underneath
4:25 Where it goes
5:29 The exact setup
7:12 Proving it works
8:06 Example 1 — an app idea
9:27 Example 3 — what is an agent
10:32 Getting more out of it
11:31 Limitations
12:36 Recap
```

Chapter titles are search surface as much as navigation — each should read like
something a person would type. 'Where it goes' is clear in context and weak in search;
'Where Custom Instructions go in ChatGPT Settings' earns the reach if you want it.
