# YouTube description — chapter markers

Paste this block into the video description. YouTube turns it into chapters
automatically as long as the first one is 00:00 and there are at least three.

```
0:00 Hook
0:39 What this actually is
2:04 Shortcuts vs. automatic
3:41 What's happening underneath
5:18 Where it goes
6:36 The exact setup
8:40 Proving it works
9:45 Example 1 — an app idea
11:22 Example 2 — SaaS or mobile
13:00 Example 3 — what is an agent
14:18 Getting more out of it
15:30 Limitations
16:48 Recap
```

Chapter titles double as search surface — each one should read like something a person
would type. 'Where it goes' is clear in context but weak in search; if you want the extra
reach, rename it 'Where Custom Instructions go in ChatGPT Settings' before pasting.
