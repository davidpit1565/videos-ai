# ChatGPT keeps notes - TREATMENT (Living Screencast, light theme, 1080x1920, 24 fps, ~25 s)
Style: Living Screencast, heavily adapted (no pixel mascot: it would read as an invented ChatGPT character; light ground, as STYLE s3 allows "follow the product's real light theme"; phone-width floating cards; no bottom caption pill because the bottom 35% is platform UI). Disclosed deviations; the full plan is design-plan-v2.md, adapted here from 9 lines to the 8 lines of script-v4.

## Three candidate structures
A. List that turns: a note list builds line by line, then one item survives. Rejected: no visible "delete" moment.
B. Before/after split screen (chat list left, notes right). Rejected: too small for phone width, quote has no room.
C. One object through the whole film: the NOTE CARD. It is born from a chat (hook), is summoned by a question, survives the chat's deletion (the twist, with the real OpenAI quote under it), is found in Settings > Personalization > Memory, then the comment box and the closing teaser. CHOSEN: the through-line gives a thumbnail-level story and one recurring shape.

## Logline / arc
ChatGPT can keep a note about you, and the note outlives the chat. Setup: claim + a chat that already produced a note. Turn: the chat is deleted, the note stays (OpenAI says so itself). Ending: where to find it, a question to the viewer, and tomorrow's teaser on the same background.

## Benchmark
Learn: Apple "guided tour" cadence, one feature per sentence; Screen Studio camera (slow push to where it happens). Not take: any UI, names, fonts, footage.

## Shot list (8 lines; times retimed to the real voice cues)
S1 L1 "ChatGPT can keep notes about you!" frame 0 complete: ChatGPT mark + big claim "CHATGPT CAN KEEP NOTES ABOUT YOU. EVEN AFTER YOU DELETE THE CHAT." (muted claim), chat card starts producing a note card.
S2 L2 "Even after you delete the chat." claim words lit as spoken; chat card dims, notes dock at right.
S3 L3 "Ask it: what do you know about me?" prompt typed in a white card (the thing to copy), generic example answer (NOT a full list: ends with "..." and a tag "not everything it remembers"), tag example · re-created.
S4 L4 "Delete the chat. The note stays." THE TWIST: chat row shrinks to nothing, note stays, ring + "still here"; real quote card with source "OpenAI Help Center, Memory FAQ" >= 3.4 s fully readable.
S5 L5 "Settings, Personalization, Memory. That's where it lives." breadcrumb "Settings > Personalization > Memory" held >= 3 s, redrawn settings sheet, toggle ON, notes listed.
S6 L6 "Did it get something wrong about you? Tell me below." empty comment card, a note card tilts toward it.
S7 L7 "The setup's in the link in bio." locked scene A: Link in bio pill + three path chips.
S8 L8 tomorrow line: scene B on the SAME background pose: ChatGPT mark, empty birthday field, "UNDER 18?" tag, Follow pill.
Native move: "spotlight freeze" (push-in on the quote) at the twist. Camera: one continuous 2D camera, zoom >= 1.00, four distinct moves (drift, push to prompt, push to quote, glide down to settings, pull back to closing).
