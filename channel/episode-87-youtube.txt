Ctrl+Z for AI mistakes: Git brings the file back

I wrote a tiny tip calculator and saved it with Git. Then I made one bad edit on purpose. I wrote that edit myself, no AI made it. The app printed "Each pays NaN". One command, git restore app.js, brought the working file back. The real git output is from one run in a local folder on my computer, 7 November 2026, git 2.43.0.

Git and GitHub are not the same thing. Git is the tool on your computer that saves pictures (commits) of your files. GitHub is a website that keeps an online copy of what Git saved.

The commands:
git init -b main
git add app.js
git commit -m "Tip calculator works"
git restore app.js
git revert --no-edit HEAD

Careful: git restore only brings back edits that were not committed yet, and the edits you undo are gone for good. After a commit, use git revert, which adds a new commit that undoes the old one and keeps your history.

Not claimed: that an AI broke the app, that this is the only way to undo a mistake, or that GitHub does the undo. Git does.
