A check said it passed. It lied.

It looked correct. It ran clean every single time. Nobody ever gave it a case that was actually broken — so it never had the chance to fail, and "never failed" got mistaken for "works."

The one test that proves a check is real: write one input you already know is broken, and run the check on that instead of on good input. If it doesn't fail, the check isn't real yet — it's just never been asked the question.
