Topic (AI trap #1 of the series, the promise of episode 83): deleting a ChatGPT chat does not delete the separate saved memory made from it. Closes the open question left in episode 70 (whether switching memory off removes what is already saved).

## Sources (read 4.11.2026, OpenAI's own pages)
- https://help.openai.com/en/articles/8590148-memory-in-chatgpt : "Deleting a chat alone does not necessarily delete a separate saved memory created from that chat." "Saved memories are stored separately from chat history. Deleting the original chat does not automatically delete a separate saved memory." "Turning off Reference chat history does not delete your saved memories." "Delete and turn off memory deletes the remembered information shown in the summary and turns Memory off. It does not delete past chats." Path: Settings, Personalization, Memory. "To remove information saved as a memory, delete the saved memory and the chat where you first shared it." "OpenAI may retain logs of deleted saved memories for up to 30 days for safety and debugging purposes."
- https://openai.com/index/memory-and-new-controls-for-chatgpt/ : "Deleting a chat doesn't erase its memories; you must delete the memory itself."
- Controls vary by plan, region and platform: the page says so; the video says "go look".
