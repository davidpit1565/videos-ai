Guess the newest Claude.

Same request to four Claude models: "Draw a pelican riding a bicycle." Which pelican is from the newest one? Type A, B, C or D below before you watch the end.

The answers: B is Haiku 5.5, D is Sonnet 5.5, A is Opus 5.5, C is Fable 5.2.

Every drawing is the real code each model wrote, one try per model, and this is the second round of two (in the first round Opus was an older version, so I used the round where all four are current). It ran through Claude Code agents, not the chat app.

The pelican test is Simon Willison's, made up in 2024 as a fun way to compare AI models. It does not measure everything an AI can do.
