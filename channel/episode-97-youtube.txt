Title: 4 Claude AIs draw a pelican on a bike (same request, one try each)

Description:
Same request to four Claude models: "Draw a pelican riding a bicycle." Haiku 5.5, Sonnet 5.5, Opus 5 and Fable 5.2. Every drawing is the real SVG code each model wrote, one try each, no picking.
The pelican test was made up by Simon Willison in 2024 as a fun way to compare AI models; it does not measure everything an AI can do.
