Title: Guess the newest Claude: 4 models draw a pelican on a bike

Description:
Same request to four Claude models: "Draw a pelican riding a bicycle." Haiku 5.5, Sonnet 5.5, Opus 5.5 and Fable 5.2. Every drawing is the real SVG code each model wrote, one try each (round 2 of 2, the round where all four are current versions), run through Claude Code agents.
The pelican test was made up by Simon Willison in 2024 as a fun way to compare AI models; it does not measure everything an AI can do.
