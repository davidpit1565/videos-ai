Your n8n workflow can fail completely — and still say "Success."

One setting causes it: On Error, set to Continue. When a node actually fails, n8n doesn't flag the workflow — the Executions list still reads green, every time. The only place the failure shows is inside that node's own output, buried in error data nobody opens. Real report from n8n's own community: a workflow silently stopped working for weeks, and the log insisted it was fine.

One extra step catches it — a branch that checks for the error field, and alerts you the moment it appears.
